Сначала разберемся с таблицами.
	Таблица "viols" с нарушениями ПДД, а "opers" с операциями по обработке нарушений ПДД.
	Т.е. таблица "viols" должна содержать все нарушения, а в таблице "opers" может не быть некоторых нарушений по которым еще не 	было обработки.

	Какие колонки нам понадобятся:
	tr_viol_id из "viols" - для подсчета количества нарушений ПДД
	time_check из "viols" - для задания периода нарушений
	refuse_code из "viols" - для выбора результирующего кода обработки
	oper_code из "opers" - для выбора типа операции обработки  
	
	Сначала мы сделаем запрос к таблице "viols" где возьмем tr_viol_id, time_check, refuse_code.
	time_check сразу переведем в формат даты, т.к. по условиям задачи время нас не интересует и зададим условие 
	"с 2018-04-01 по 2018-04-20".
		

	SELECT
          tr_viol_id,
          time_check::date AS viol_date,
          refuse_code
    	FROM viols
    	WHERE time_check >= DATE '2018-04-01' 
	AND time_check <  DATE '2018-04-21'
