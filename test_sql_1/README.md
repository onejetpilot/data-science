Агрегация нарушений ПДД и операций обработки
Описание задачи

Даны две таблицы:

viols — таблица с нарушениями ПДД. Содержит все зафиксированные нарушения.

opers — таблица с операциями по обработке нарушений. Для части нарушений записи могут отсутствовать.

Требуется для заданного периода посчитать агрегаты по нарушениям ПДД с учётом наличия или отсутствия операции обработки с кодом 29.

Период: с 2018-04-01 по 2018-04-20 включительно (верхняя граница задаётся как < 2018-04-21).

Используемые поля

Из таблицы viols:

tr_viol_id — идентификатор нарушения

time_check — дата и время фиксации нарушения

refuse_code — результирующий код обработки

Из таблицы opers:

tr_viol_id — идентификатор нарушения

oper_code — код операции обработки
